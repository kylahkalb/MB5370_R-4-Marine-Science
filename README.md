## About This Repository

This repository documents my practical coursework for the R for Marine Science module of MB5370: Techniques in Marine Science 1 at James Cook University.

The module focuses on importing, cleaning, transforming, analysing, and visualising data using R, with applications to ecological and marine science research.

## Workshop Overview

**Workshop 1 — Foundations of Data Science**

Importing different data formats, exploring data structures, and manipulating ecological datasets using tidyverse functions such as `select()`, `filter()`, `mutate()`, `group_by()`, and `summarise()`.

**Workshop 2 — Advanced Data Wrangling**

Restructuring datasets, cleaning strings and dates, joining tables, managing missing values, and extracting meaningful information from complex datasets.

**Workshop 3 — Plot Deconstruction**

Critically evaluating a published marine science figure and reconstructing it using digitised data and ggplot2 to improve visual communication.

## Repository Structure

- `code/` — R scripts and practical coding exercises.
- `data/` — Datasets used throughout the workshops.
- `docs/` — Quarto source documents, rendered HTML reports, and figures.
- `outputs/` — Generated analysis outputs.

## Skills Developed

- Data import and cleaning
- Data wrangling with tidyverse and dplyr

- Working with dates and strings

- Handling missing observations
- Scientific visualisation with ggplot2
